An invented passport spread for the Republic of Vessalia, a tidal island nation: a data page with portrait, machine-readable zone and consistent issue dates, plus arrival and departure stamps — including the condition that the bearer may remain until the tide returns. `render.py` draws the spread and `main.py` writes it to `/output/entry.png`.

## Run it

```sh
python3 render.py && python3 main.py
```
